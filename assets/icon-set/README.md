# Claudepot icon set

Isometric block on an anodised gray plate. Seven points, four flat planes,
lit from upper left. Every coordinate is a multiple of 16 on a 1024 grid.

## macOS 26

Import `macos/layer-1-plate.svg` and `macos/layer-2-glyph.svg` into Icon
Composer as background and foreground layers. Do not add an enclosure - the
system draws the squircle, corners and shadow. Annotate Default, Dark and
Mono; the Mono channel is the tray silhouette, not the block, because a
single-colour render cannot carry the four plane tones.

`actool` emits both the layered asset for Tahoe and a fallback `icon.icns`
for Sequoia and earlier. Keep the runtime `setApplicationIconImage` override
against the 512 PNG - it is no longer load-bearing for crispness but it costs
nothing.

## Windows

Plateless glyph, transparent background, nearly filling the 48-unit grid.
Build `icon.ico` from the PNGs at 16, 24, 32, 48, 64 and 256 with PNG
payloads embedded verbatim - never `magick *.png icon.ico`, which falls back
to raw BMP per layer.

## Linux

`linux/claudepot.svg` into `hicolor/scalable/apps/`, `claudepot-symbolic.svg`
into `hicolor/symbolic/apps/`, and PNGs at 32, 48, 64, 128 and 256 into the
matching `hicolor/<size>x<size>/apps/` directories. GNOME draws no enclosure,
so the rounded base is part of the artwork here and only here.

## The grain

The plate texture is generated by `feTurbulence`, so it is resolution-dependent:
the noise is computed at render size and coarsens relative to the tile as the
tile shrinks. Below 48 it reads as dirt rather than as a finish. The 32 and 16
rasters therefore come from `app-icon-flat.svg` (plate `#DCD8D2`, no grain).
Rasterise per size rather than shipping one filtered SVG into every slot.

## Regenerating rasters

    rsvg-convert -w 512 -h 512 app-icon.svg -o png/icon-512.png
    rsvg-convert -w 32  -h 32  app-icon-flat.svg -o png/icon-32.png

Full ladder: 1024, 512, 256, 128, 96, 64, 48 from `app-icon.svg`; 32 and 16
from `app-icon-flat.svg`; tray at 36 and 44 from `tray/*.svg`.
