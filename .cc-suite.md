## Authority — read this before editing

This file configures **cc-suite**. It is **not** a source of truth
about Claudepot.

Anything that describes how the project works — the domain model,
layering rules, keychain surfaces, path handling, design tokens,
store inventory, CI gate commands — is canonical in the files listed
below. **Do not restate any of it here.** A restated fact is a copy,
and copies drift silently: on 2026-07-26 this file still declared a
four-noun domain model months after `agent` was added as the fifth,
and an audit built its prompt from this file and reported the real
architecture as "architectural drift". The same audit found the
clippy gate here naming the wrong crates.

Read these first. They are authoritative and override anything in
this file:

- **`AGENTS.md`** — architecture, build + test commands, the SQLite
  and JSON store inventory, release-validation gates.
- **`.claude/rules/`** — the enforced rules. Read the whole
  directory; do not assume a fixed list, it grows.
- **`.github/workflows/ci.yml`** — the exact commands CI runs. When
  you need a gate command, read it from here rather than trusting a
  transcription.

If a statement in this file conflicts with those, they win and the
statement here is a bug — fix it by deleting the copy, not by
editing it to match.
